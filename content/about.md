# About This Project

This static site generator is intentionally small. The goal is to understand the moving parts of a build pipeline instead of hiding everything behind a framework.

## What It Does

- Reads Markdown files from the content directory
- Parses simple front matter for metadata
- Renders pages through a shared Jinja2 template
- Generates a navigation bar for every page
- Copies static assets into the final output

## Why Build It Yourself

You get direct practice with file I/O, templating, and command-line interfaces. Those skills transfer to much larger tools later.
